# Contributing

1. Fork the repo at https://github.com/neardaniel-pls/fedora-ai-setup
2. Create a feature branch: `git checkout -b feature/your-feature`
3. Make your changes
4. Push and open a pull request

## Guide Guidelines

- Test all commands on a fresh Fedora installation
- Include prerequisites at the top of each guide
- Use code blocks for all terminal commands
- Add troubleshooting sections for common issues
- Keep guides focused on one tool/setup process

## Commit Messages

Use conventional commits: `feat`, `fix`, `docs`, `refactor`, `chore`
